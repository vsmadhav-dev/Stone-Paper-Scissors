# Stone Paper Scissors ✂️🪨📄

A clean, interactive, and responsive web-based implementation of the classic **Stone Paper Scissors** (Rock Paper Scissors) game. Built using modern HTML5, CSS3, and JavaScript, this game allows a user to play against a computer opponent with real-time score tracking and feedback.

---

## 🎮 How the Game Works

1. **User Selection:** 
   The player chooses one of three moves: **Stone**, **Paper**, or **Scissors**.

2. **Computer Choice:** 
   The computer randomly generates its own choice (Stone, Paper, or Scissors) using JavaScript's random selection logic.

3. **Determining the Winner:** 
   The game evaluates the choices based on the standard rules:
   - **Stone vs. Scissors:** Stone breaks Scissors *(Stone wins)*
   - **Scissors vs. Paper:** Scissors cut Paper *(Scissors win)*
   - **Paper vs. Stone:** Paper covers Stone *(Paper wins)*
   - **Same Choice:** It's a draw/tie.

4. **Scoreboard & Feedback:**
   - The user score or computer score updates instantly based on who wins the round.
   - A message display updates to show the result of the current round.

---

## 🚀 Features

- **Interactive UI:** Smooth button interactions and visual feedback for player choices.
- **Dynamic Score Tracking:** Real-time updates for user and computer scores.
- **Randomized AI:** Fair computer move generation for unpredictable gameplay.
- **Responsive Design:** Playable across different screen sizes and devices.

---

## 🛠️ Tech Stack

- **HTML5:** Markup and structure.
- **CSS3:** Styling, layout, and visual presentation.
- **JavaScript (ES6):** Game logic, event handling, DOM manipulation, and randomized choices.
